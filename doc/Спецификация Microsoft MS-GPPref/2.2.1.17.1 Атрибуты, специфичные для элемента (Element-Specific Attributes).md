# Спецификация Microsoft MS-GPPref
## 2.2.1.17.1 Атрибуты, специфичные для элемента (Element-Specific Attributes)

> **Источник:** [Microsoft Learn - MS-GPPref](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-gppref/e5c0cb82-7768-4b9d-ba87-2a8a4684afee)  
> **Раздел:** Group Policy Preferences: Registry Settings

Эта таблица описывает атрибуты, используемые для настройки элементов реестра в групповых политиках (Group Policy Preferences).
Данная таблица описывает атрибуты XML, используемые для настройки элементов реестра в групповых политиках (Group Policy Preferences).

| Имя атрибута | Описание |
| :--- | :--- |
| **action** | *(необязательный)* Определяет действие, выполняемое над элементом реестра. Допустимые значения: **C**, **D**, **R**, **U**.<br><br>Значение по умолчанию: **U** (Update).<br><br>### Варианты действий:<br>• **Create (C) — Создать:**<br>  — Создаёт новое значение или раздел реестра.<br>  — Если элемент уже существует, действие не выполняется.<br><br>• **Delete (D) — Удалить:**<br>  — Удаляет значение реестра или весь раздел (вместе со всеми подразделами и значениями).<br><br>• **Replace (R) — Заменить:**<br>  — Полностью удаляет существующий элемент и создаёт его заново с указанными параметрами.<br>  — *Для значения:* перезаписывает все параметры значения.<br>  — *Для раздела:* удаляет все подразделы и значения, оставляя только имя значения по умолчанию без данных.<br>  — Если элемент не существует, он будет создан.<br><br>• **Update (U) — Обновить:**<br>  — Изменяет только указанные в элементе настройки.<br>  — Остальные параметры существующего элемента остаются без изменений.<br>  — Если элемент не существует, он будет создан. |
| **default** | *(необязательный)* Устанавливается в **1**, чтобы указать, что настраивается значение по умолчанию для раздела реестра (`(Default)`). |
| **hive** | *(обязательный)* Имя корневого раздела (улья) реестра. Допустимые значения:<br><br>• `HKEY_CLASSES_ROOT` — псевдоним для `HKEY_LOCAL_MACHINE\Software\Classes`<br>• `HKEY_CURRENT_USER` — псевдоним для `HKEY_USERS\<загруженный профиль>`<br>• `HKEY_LOCAL_MACHINE` — настройки компьютера (влияют на всех пользователей)<br>• `HKEY_USERS` — настройки пользователей (влияют на отдельных пользователей)<br>• `HKEY_CURRENT_CONFIG` — псевдоним для `HKEY_LOCAL_MACHINE\System\CurrentControlSet\Hardware Profiles\Current` |
| **key** | *(обязательный)* Путь к разделу реестра. Не должен содержать имя улья (hive) или ведущие/замыкающие обратные слеши (`\`).<br><br>Пример: `Software\Policies\Microsoft\Windows` |
| **name** | *(необязательный)* Имя настраиваемого значения реестра.<br><br>• Если настраивается значение: укажите имя значения **или** установите атрибут `default="1"` для настройки значения по умолчанию.<br>• Если настраивается только раздел реестра (без значения): поле должно оставаться пустым. |
| **type** | *(необязательный)* Тип данных значения реестра. Обязательно, если настраивается значение.<br><br>Допустимые значения:<br>• `REG_SZ` — строка<br>• `REG_DWORD` — 32-битное число<br>• `REG_EXPAND_SZ` — расширяемая строка<br>• `REG_MULTI_SZ` — мультистрока<br><br>Если настраивается только раздел реестра: поле должно быть пустым. |
| **value** | *(необязательный)* Данные, записываемые в значение реестра.<br><br>• Применяется только при действиях **Create**, **Replace** или **Update**.<br>• Требуется наличие установленного атрибута **type**.<br>• Если настраивается только раздел реестра: поле должно быть пустым. |
| **displayDecimal** | *(необязательный)* Устанавливается в **1**, чтобы указать, что числовое значение типа `REG_DWORD` должно отображаться в десятичной системе счисления (вместо шестнадцатеричной). |
| **bitfield** | *(необязательный)* Устанавливается в **1**, если значение реестра представляет собой битовое поле (серию независимых битовых флагов). |
| **defaultValue** | *(необязательный)* Задает начальное значение для битового поля. Используется только если `bitfield="1"`. В противном случае игнорируется. |
| **SubProp** | *(необязательный)* Коллекция подэлементов для настройки отдельных битов в битовом поле. Каждый подэлемент должен содержать три атрибута:<br><br>• **id** *(string)*: пользовательское имя для группы битов<br>• **value** *(number)*: числовое значение, применяемое к битам<br>• **mask** *(number)*: битовая маска, определяющая, какие биты затрагиваются |
| **desc** | *(необязательный)* Текстовый комментарий или описание элемента, видимое в интерфейсе групповых политик. |

---

### Пример использования (XML)

```xml
<Registry 
    action="U" 
    hive="HKEY_LOCAL_MACHINE" 
    key="Software\Policies\Example" 
    name="SettingValue" 
    type="REG_DWORD" 
    value="1" 
    displayDecimal="1"
    desc="Пример настройки реестра через GPP" />
